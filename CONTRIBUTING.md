# Contributing to KasiCircleApp

We love receiving contributions from the community and our team.

## Getting Started

- Fork the repository on GitHub.
- Clone the forked repository to your local machine.
- Create a new branch for your changes.

## Making Changes

- Make your changes in a separate branch.
- Ensure that your code follows the project's coding conventions.
- Add or update tests as appropriate.
- Make sure all tests pass before submitting a pull request.

## Submitting a Pull Request

- Push your changes to your fork on GitHub.
- Submit a pull request to the `main` branch of the upstream repository.
- Provide a clear description of the changes you have made.
